Types and Components of Computer Systems

This topic sets up the vocabulary for the whole course: what hardware and software are, what the main parts of a computer system do, how operating systems let people control them, the types of computer available, and the emerging technologies changing everyday life.

Syllabus coverage: 1.1 Hardware and software · 1.2 The main components of computer systems · 1.3 Operating systems · 1.4 Types of computer · 1.5 Emerging technologies
1.1

Hardware and Software

Hardware

Hardware consists of the physical components of a computer system - the parts you can touch.

Internal components

  • Central Processing Unit (CPU) / processor - carries out the instructions of a program
  • Motherboard - the main circuit board that everything else plugs into and communicates through
  • Internal memory - random access memory (RAM) and read-only memory (ROM)

Other hardware components

  • Graphics card - processes and outputs images to the monitor
  • Sound card - converts digital sound data into signals for speakers, and audio input into digital data
  • Network Interface Card (NIC) - connects the computer to a network, and holds the MAC address
  • Camera - captures still images or video as input
  • Internal and external storage devices - hard disk drives, solid-state drives, optical drives, portable drives
  • Input and output devices - keyboard, mouse, monitor, printer and so on

Software

Software are programs for controlling the operation of a computer or the processing of electronic data.
Applications software

Provides the services that the user requires to solve a task.

  • Word processing
  • Spreadsheet
  • Database management systems
  • Control and measurement software
  • Applets and apps
  • Video editing
  • Graphics editing
  • Audio editing
  • Computer aided design (CAD)
System software

Provides the services that the computer requires to operate.

  • Compilers - translate a whole high-level program into machine code
  • Linkers - join compiled modules into one executable program
  • Device drivers - let the operating system communicate with hardware
  • Operating systems - manage the hardware and provide the user interface
  • Utilities - housekeeping tools such as anti-virus, file compression, defragmentation
Exam tip: "software runs the computer, applications run for the user" is a safe one-line distinction. Never name a brand - no marks are awarded for brand names of software packages or hardware.

Analogue and digital data

Analogue data
  • Continuously varying - it can take any value within a range
  • Physical quantities in the real world are analogue: temperature, sound, light, pressure
  • Represented by a smooth, continuous wave
Digital data
  • Discrete - it uses separate, fixed values only
  • Represented in a computer as 1s and 0s
  • Represented by a stepped, square waveform

Why conversion is needed

  • Analogue to digital (ADC) - a computer can only process digital data, so readings from sensors and microphones must be converted before the computer can use them.
  • Digital to analogue (DAC) - actuators, motors, valves and speakers respond to analogue signals, so the computer's digital output must be converted before it can control these devices.
Common exam question: "A computer controls a greenhouse heater using a temperature sensor. Explain why an ADC and a DAC are needed." The sensor produces a continuously varying (analogue) reading that must be converted to digital for the processor; the processor's digital signal must be converted back to analogue to drive the heater.
Check your understanding
Classify each of these as applications software or system software: a device driver, a CAD package, a linker, an audio editor.
System software: device driver, linker. Applications software: CAD package, audio editor.
State two differences between analogue and digital data.
Analogue data varies continuously and can take any value in a range; digital data is discrete and uses only fixed values, stored as 1s and 0s. Analogue is drawn as a smooth wave, digital as a stepped/square wave.
1.2

The Main Components of Computer Systems

Central Processing Unit (CPU)

  • The CPU processes the instructions entered into the computer in order to produce an output.
  • It fetches each instruction, decodes what it means, and executes it.
  • It controls the movement of data between memory, input devices and output devices.
  • It performs all arithmetic and logical operations.
Remember the chain: INPUT → PROCESSING (CPU) → OUTPUT, with STORAGE available at every stage.

Input and output devices

Input devices
  • Allow data and instructions to be put into the computer
  • Convert the user's actions or real-world quantities into digital data
  • Examples: keyboard, mouse, scanner, microphone, sensor
Output devices
  • Allow results to be taken out of the computer in a form people or machines can use
  • Convert digital data into text, images, sound or movement
  • Examples: monitor, printer, speaker, actuator
A touch screen is the classic device that is both: it accepts input by touch and outputs the display.

Backing storage

  • Non-volatile - it keeps files permanently when the power is switched off.
  • Much larger capacity and much cheaper per byte than internal memory.
  • Data must be copied into RAM before the CPU can process it - backing storage is not directly addressable.
  • Slower to access than internal memory.
Link: this is covered in full in Topic 3, Storage Devices and Media.
Check your understanding
A computer has 8 GB of RAM and a 512 GB SSD. Explain why both are needed.
RAM is very fast and directly addressable, so it holds the data and programs in current use - but it is volatile, so everything is lost when the power goes off, and it is too small and too costly to hold all of the user's files. The SSD is non-volatile and far larger, so it keeps files and software permanently, ready to be loaded into RAM when needed.
Why is ROM used to store the boot program rather than RAM?
ROM is non-volatile, so the start-up instructions are still there when the computer is switched on. RAM would be empty, because its contents are lost every time the power is removed.
1.3

Operating Systems

What an operating system does

An operating system is system software that manages the hardware and resources of a computer and provides the interface through which the user communicates with it.
  • Manages the processor, memory, backing storage and peripherals
  • Handles files - saving, loading, copying, deleting and organising them
  • Handles errors and provides security, including user accounts and passwords
  • Provides the user interface

Types of interface

Command Line Interface (CLI)

Characteristics

  • The user types in commands to carry out every task
  • The user must learn and remember the exact commands and their syntax
  • The user is in direct communication with the computer
Advantages
  • The user is in direct control and can change settings the GUI hides
  • Uses very little memory and processing power
  • Commands can be combined into scripts, which is fast for repeated tasks
Disadvantages
  • The user has to learn many commands
  • All commands must be typed with perfect accuracy - one mistyped character fails
  • Slow to use for beginners and harder to learn
Graphical User Interface (GUI)

Characteristics

  • Uses windows, icons, menus and pointers (WIMP)
  • The user selects items by clicking or tapping instead of typing commands
  • Some GUIs are designed for touch, using post-WIMP gestures such as pinch and swipe
Advantages
  • Much easier for a beginner - no commands to remember
  • Consistent look across applications, so skills transfer
  • Little chance of a typing error stopping a task
Disadvantages
  • Uses considerably more memory and processing power
  • The user is limited to the options the designer provided
  • Can be slower for an expert than typing a command
Dialogue based interface

Characteristics

  • The user speaks to the device and it responds, often in speech
  • Used in smart speakers, in-car systems and voice assistants
Advantages
  • The user's hands and eyes stay free - safer when driving
  • Very useful for users with a physical disability
  • No commands or menus to learn; the user speaks naturally
Disadvantages
  • Accents, unusual words and background noise cause recognition errors
  • The vocabulary understood is still limited
  • Privacy concerns, because a microphone is always listening
Gesture based interface

Characteristics

  • Cameras or sensors detect body or hand movements and turn them into commands
  • Used in games consoles, in-car controls and some medical equipment
Advantages
  • No need to touch anything, which is hygienic and safe in an operating theatre
  • Natural and quick to use once learned
  • Keeps the driver's hands near the wheel
Disadvantages
  • Only a limited set of gestures can be recognised
  • The user must stay within range of the sensor
  • Unintended movements can be read as commands
Check your understanding
A network technician prefers a CLI while an office worker prefers a GUI. Explain why.
The technician knows the commands and needs direct control over settings the GUI does not expose, and can script repeated jobs, which is faster. The office worker is not a computer expert, so a GUI is easier to learn and use, with icons and menus instead of memorised commands.
Give one situation where a gesture based interface is better than a touch screen.
In an operating theatre a surgeon can control images without touching anything, which keeps their hands sterile. (A driver controlling a car system without taking their hands from the wheel is equally acceptable.)
1.4

Types of Computer

Desktop computer

Characteristics

  • Made up of separate components - system unit, monitor, keyboard, mouse - connected together
  • Stays in one place and is powered from the mains
  • Components can be upgraded or replaced individually
Uses
  • Office and business management
  • Education
  • Gaming and entertainment
Advantages
  • Expandable - easy to add memory, storage or a better graphics card
  • Cheaper than a laptop of the same specification
  • Less likely to be stolen; easier and cheaper to repair
  • Better cooling allows more powerful processors
Disadvantages
  • Not portable - it must be used in one place
  • Many cables and separate parts to set up
  • Stops working in a power cut, as there is no battery
  • Takes up a lot of desk space

Mobile computers

Laptop computer
  • Monitor, keyboard, pointing device and processor built into one case
  • Battery powered and light enough to carry
  • Full keyboard and the most processing power of the mobile devices
Smartphone
  • Pocket-sized, with a touch screen and on-screen keyboard
  • Connects over wi-fi and mobile phone networks
  • Runs apps, and includes camera, GPS and sensors
Tablet computer
  • Larger touch screen than a phone, with no physical keyboard
  • Very fast to start up, long battery life
  • Uses solid-state storage, so no moving parts
Phablet computer
  • Sits between a smartphone and a tablet in screen size
  • Makes phone calls like a smartphone but gives more screen for reading and video
  • Still fits in a large pocket or bag
Uses of mobile computers
  • Office and business management, including working while travelling
  • Education
  • Gaming and entertainment, including streaming
  • Remotely controlled devices, such as controlling home heating, lighting or a drone

Advantages of mobile computers
  • Portable - can be used almost anywhere, including on the move
  • One unit to carry, with no trailing cables
  • Battery powered, so they keep working in a power cut
  • Connect wirelessly to networks and to the internet
Disadvantages of mobile computers
  • Limited expandability - parts are usually not upgradeable
  • Smaller screens and keyboards make long tasks harder
  • Easier to lose, damage or have stolen, which is a data security risk
  • Less processing power and shorter working time between charges
Check your understanding
A graphic designer buys a desktop rather than a laptop. Give two reasons.
A desktop is expandable, so extra memory, storage and a more powerful graphics card can be fitted as the work demands. It also gives more processing power and a larger screen for the same money, and is cheaper and easier to repair or upgrade.
Explain why tablets start up more quickly than most desktop computers.
Tablets use solid-state storage with no moving parts, so there is no drive to get up to speed, and their operating systems are smaller and designed to resume rather than fully reboot.
1.5

Emerging Technologies

Artificial Intelligence (AI)

Artificial Intelligence is the use of computer systems to carry out tasks that would normally need human intelligence, such as recognising speech, making decisions and learning from data.

Impact on everyday life

  • Voice assistants, translation and predictive text
  • Medical diagnosis support and analysis of scans
  • Autonomous vehicles and traffic management
  • Recommendations on shopping, music and video services
  • Fraud detection in banking and filtering of spam email
Positive effects
  • Dangerous, repetitive and dirty jobs can be done by machines
  • Decisions can be made faster and from far more data than a person could read
  • Services can run 24 hours a day at lower cost
  • Greater accuracy in tasks such as spotting patterns in medical images
Negative effects
  • Unemployment as tasks are automated, and the need for retraining
  • Systems can be biased if the data they learned from was biased
  • Large amounts of personal data are collected, raising privacy concerns
  • People may rely on decisions they cannot check or explain
  • High cost of development and of the expertise needed

Extended reality: virtual and augmented

Virtual reality (VR)
  • A fully computer-generated environment, usually seen through a headset
  • Replaces what the user can see of the real world
  • Uses: pilot and surgical training, architecture walkthroughs, gaming, treating phobias
Augmented reality (AR)
  • Adds computer-generated images or data on top of the real world
  • Seen through a phone camera, tablet or smart glasses
  • Uses: navigation arrows on a live street view, seeing furniture in your own room before buying, maintenance instructions overlaid on machinery
Positive effects
  • Training can be done safely, and mistakes cost nothing
  • Expensive or impossible experiences become available, for example visiting a museum in another country
  • Helps customers make better decisions before buying
  • Improves access to education and to remote expertise
Negative effects
  • Headsets and software are expensive, and the equipment dates quickly
  • Can cause eye strain, headaches and motion sickness
  • Users may become isolated from real social contact
  • A user wearing a headset or looking at an AR screen may not notice real hazards
Exam tip: the giveaway difference is that VR replaces the real world and AR adds to it.
Check your understanding
A furniture shop offers an app that shows a sofa in the customer's living room. Name the technology and give one benefit to the shop.
This is augmented reality, because the computer-generated sofa is added on top of a live view of the real room. The shop benefits from fewer returns, because customers can see whether the item fits and suits the room before buying, and it can sell without holding large showroom stock.
Give one positive and one negative effect of using AI in medical diagnosis.
Positive: AI can analyse scans and patient data faster and across far more cases than a doctor, helping to spot problems early. Negative: if the training data was biased or incomplete the system may be wrong for some groups of patients, and staff may rely on a decision they cannot check.
