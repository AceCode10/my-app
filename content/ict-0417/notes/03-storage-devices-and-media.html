Cambridge IGCSE ICT 0417 · Topic 3

Storage Devices and Media

Every file you keep after the power goes off lives on backing storage. This topic asks you to know the three storage technologies - magnetic, optical and solid-state - and, for each one, its characteristics, its uses, its media, and its advantages and disadvantages. You also need to be able to tell backing storage apart from internal memory.

Syllabus coverage: Topic 3 is not divided into numbered sub-sections in the 0417 syllabus (2026-2028). The sections below are teaching sections; between them they cover both syllabus strands - Storage devices and Storage media.
3.1

Storage Media and Storage Devices

The difference you must be able to state Storage devices · Storage media

Examiners award marks for keeping these two words apart. They are not interchangeable.

Storage media
  • The hardware on which the data is actually stored
  • Examples: a CD, a DVD, a hard disk platter, magnetic tape, an SD card
  • Often removable from the device that reads it
Storage device
  • The hardware that reads from and writes to the media
  • Examples: a DVD drive, a tape drive, a card reader, a hard disk drive
  • Contains the motor, read/write head or laser
Watch out: in a fixed hard disk drive and in a solid-state drive the media and the device are sealed into one unit, so the same name is used for both. In an optical system they are clearly separate - the disc is the medium, the drive is the device.

Secondary (backing) storage

Backing storage is non-volatile storage held outside the CPU. It keeps its contents permanently, even when the computer is switched off.

The three technologies

Magnetic
  • Data stored by magnetising tiny areas of a surface
  • Has moving parts
  • Hard disks, magnetic tape
Optical
  • Data stored by burning pits into a reflective layer with a laser
  • Has moving parts
  • CD, DVD, Blu-ray
Solid-state
  • Data stored as charge in NAND flash memory cells
  • No moving parts
  • SSD, pen drive, memory card

Access methods

  • Serial access - the device must read through every record from the start until it reaches the one it wants. Used by magnetic tape. Very slow for finding one record.
  • Direct (random) access - the device can go straight to the position of the data it wants. Used by hard disks, optical discs and solid-state media.
Check your understanding
A student writes "a DVD is a storage device". Correct the statement and explain why.
A DVD is a storage medium - it is the surface the data is actually stored on. The DVD drive is the storage device, because it is the hardware that reads from and writes to the disc.
Why is magnetic tape described as having "prolonged data access times"?
Tape uses serial access, so the drive must wind through all the data that comes before the record it wants. A hard disk uses direct access and can move its head straight to the required track and sector.
3.2

Magnetic Storage

How magnetic storage works

  • The surface of the medium is coated with a material that can be magnetised.
  • A read/write head passes over the surface and magnetises tiny areas in one of two directions.
  • The two directions represent 1 and 0.
  • The surface is divided into concentric tracks, which are split into sectors.
  • Because the magnetism stays after the power is removed, magnetic storage is non-volatile.
Exam tip: anything that stores data using magnetism can be corrupted by a strong magnetic field. That single fact is worth a mark in many "disadvantages" questions.

Magnetic tape

Magnetic tape Magnetic media

Characteristics

  • A long plastic ribbon coated with a magnetic layer, wound in a cassette
  • Read and written by a tape drive
  • Serial access only
  • Very high capacity and known to be very stable over long periods
Uses
  • Used as a backup medium where vast amounts of data need to be stored
  • Used in long-term archiving of data, because tapes have huge storage capacities and are very stable
  • Batch processing systems, for example utility billing and payroll, where a whole file is read in order
Advantages
  • Generally less expensive than hard disk drives
  • Huge data storage capacity
  • Very stable, so suitable for archives kept for years
  • Data transfer rate is fast once the tape is running, which suits whole-file backups
Disadvantages
  • Prolonged data access times, because it uses serial access
  • When updating, another tape is needed to store the final updated version
  • Affected by magnetic fields - a strong field can corrupt the data stored on the tape
  • Tape and drive are bulky compared with solid-state media

Magnetic hard disks and hard disk drives (HDD)

Fixed hard disk drive Magnetic device

Characteristics

  • One or more rigid platters (the media) spinning at high speed inside a sealed unit
  • Read/write heads move across the platters on an arm - so it has moving parts
  • Direct access, so any file can be reached quickly
  • Fitted inside the computer and not normally removed
Uses
  • To store the operating system, systems software and working data/files
  • Storing applications files
  • Real-time systems and online systems, such as booking and banking systems, where data must be found instantly
  • File servers in a network
Advantages
  • Generally offers larger storage capacities than SSDs
  • More affordable per gigabyte compared to SSDs
  • Well suited to long-term storage needs
  • Fast direct access compared with tape or optical media
Disadvantages
  • Has moving parts, making it more prone to damage if knocked or dropped
  • Heavier and bulkier compared to SSDs
  • Higher power consumption
  • Generates more heat and noise
  • Can be corrupted by strong magnetic fields
Portable hard disk drive Magnetic device

Characteristics

  • The same technology as a fixed HDD, but in a protective case that plugs into a USB port
  • Can be carried between computers and disconnected without opening the case
Uses
  • Backing up whole systems or large folders
  • Transferring very large files, such as video, between computers
  • Storing an offsite copy of company data
Advantages
  • Very large capacity for the price
  • Portable, so data can be taken offsite or shared
  • Fast data transfer rate over USB
Disadvantages
  • Still contains moving parts, so it is easily damaged if dropped while spinning
  • Easier to lose or have stolen than a fixed drive, which is a security risk
  • Heavier and larger than a pen drive or memory card
Check your understanding
A company backs up its 40 TB database every night. Give two reasons why magnetic tape suits this task better than optical discs.
  • Tape has a huge storage capacity, so the whole backup fits on very few tapes, while optical discs hold far less data and would need hundreds of discs.
  • Tape is less expensive per gigabyte and is very stable for long-term archiving.
  • The backup is written and read as a whole file, so serial access is not a drawback.
Explain why an HDD is a poor choice for a computer that will be carried around a building site.
An HDD has moving parts - spinning platters and moving read/write heads - so knocks and vibration can damage the drive and corrupt data. It is also heavier and uses more power. A solid-state drive, which has no moving parts, would be more reliable.
Recap
  • Magnetic storage magnetises tiny areas of a surface to store 1s and 0s.
  • Tape = serial access, huge capacity, cheap, used for backup and archiving.
  • HDD = direct access, holds the OS and working files, cheaper per GB than SSD but has moving parts.
  • All magnetic media can be corrupted by strong magnetic fields.
3.3

Optical Storage

How optical storage works

  • Optical storage holds data by burning 'dots' (pits) onto the surface of the disc with a high-powered laser.
  • The burned pits and the unburned areas (lands) reflect the reading laser differently.
  • The drive detects the change in reflection and converts it into 1s and 0s.
  • Data is written in a single spiral track running from the centre outwards.

Why capacities differ

  • CD and DVD use red lasers. DVDs have a higher capacity than CDs because the pits are smaller and they can use dual-layering.
  • Blu-ray uses a blue laser, which has a shorter wavelength, allowing the pits to be even smaller. It holds up to 5 times more data than a DVD (for example 25 GB per layer).
Exam tip: "shorter wavelength → smaller pits → more pits in the same area → higher capacity" is the chain of reasoning examiners look for.

Disc formats you should recognise

ROM (CD-ROM, DVD-ROM, BD-ROM)
Read-only. The pits are pressed in during manufacture, so the user can read the data but never change it. Used for commercial software, games and films.
R (CD-R, DVD-R, BD-R)
Recordable - the user can write to the disc once, using the drive's laser to burn the dye layer. Useful where a permanent, unalterable record is wanted.
RW (CD-RW, DVD-RW, BD-RE)
Rewritable - the layer can be changed back and forth between two states, so the disc can be written to and erased many times. Useful for short-term backups.
DVD-RAM
Uses concentric tracks instead of one spiral, so it can read and write at the same time and rewrite very many times. Used in recording devices such as set-top boxes and CCTV.

Advantages and disadvantages of optical storage

Advantages
  • Less expensive than hard disk drive systems
  • Very portable, as they are small and light
  • Not affected by magnetic fields
  • ROM and R discs give a permanent copy that cannot be altered
Disadvantages
  • Hold far less data than hard disk drives or memory sticks
  • Very slow data transfer rate and access times compared with hard disks and solid-state media
  • The surface is easily scratched, which makes data unreadable
  • Many modern laptops no longer include an optical drive
Check your understanding
Explain why a Blu-ray disc can store more data than a DVD of the same physical size.
Blu-ray uses a blue laser with a shorter wavelength than the red laser used for DVDs. A shorter wavelength can burn and read smaller pits, so more pits fit into the same area of disc and the capacity rises - up to about five times that of a DVD.
A music shop sells albums on CD. Give one reason why CD-ROM rather than CD-RW is used.
A CD-ROM is read-only, so the customer cannot overwrite or erase the recording. It is also cheaper to mass-produce by pressing, and protects the producer's content.
3.4

Solid-State Backing Storage

How solid-state storage works

  • No moving parts; it uses NAND flash memory and transistors with floating gates and control gates to store data.
  • A charge is trapped on the floating gate; whether the charge is present or absent represents 1 or 0.
  • The charge stays when the power is removed, so solid-state storage is non-volatile.
  • Solid-state media include solid-state drives (SSD), pen drives and memory cards (SD, xD, CFast).

Solid-state drives (SSD)

Solid-state drive Solid-state device

Characteristics

  • Flash memory chips on a board, in the same form factor as a hard drive or fitted directly to the motherboard
  • Available as a fixed internal drive or a portable external drive
  • Direct access with no seek time, because there is no head to move
Uses
  • Main drive in laptops, tablets and smartphones
  • Holding the operating system and applications so they load quickly
  • Servers that need very fast response, such as web and database servers
Advantages
  • More reliable - there are no moving parts to go wrong
  • Considerably lighter, which makes them suitable for laptops
  • They do not have to 'get up to speed' before they work properly
  • Lower power consumption, so battery life is longer
  • Run much cooler than HDDs and are much quieter
  • Because there are no moving parts they can be made very thin
  • Data transfer speed is much faster than for HDDs
Disadvantages
  • Limited endurance - a finite number of write operations compared with magnetic media
  • Higher cost per gigabyte - SSDs are generally more expensive than HDDs for the same amount of storage
  • Typically a more limited maximum storage capacity
  • Data recovery after failure is usually harder than on a magnetic disk

Pen drives and flash drives

Pen drive / flash drive / memory stick Solid-state

Characteristics

  • Flash memory with a built-in USB connector, so no separate reader is needed
  • Very small, light and robust; powered by the USB port
Uses
  • Transporting files between computers, for example coursework between school and home
  • Carrying small backups and portable applications
  • Distributing software or promotional material
Advantages
  • Extremely portable and robust - no moving parts
  • Plugs straight into a USB port on almost any computer
  • Faster access than optical media
Disadvantages
  • Small size makes them easy to lose or steal, which risks data loss or disclosure
  • Much smaller capacity than a hard disk
  • Can be forgotten in the port, and can carry viruses between machines

Memory cards

Memory cards Solid-state media

Different types of memory card

  • SD cards (secure digital card) - widely used in portable devices
  • xD cards (extreme digital card) - mainly found in older digital cameras
  • CFast cards (compact, fast card) - designed for high-speed data transfer in professional cameras
Uses
  • Storing photographs and video in digital cameras and camcorders
  • Expanding the storage of smartphones, tablets and games consoles
  • Holding the operating system in small single-board computers
Advantages
  • Very compact
  • Because they have no moving parts, they are very durable
  • They can hold large amounts of data
  • Low power consumption, which suits battery-powered devices
Disadvantages
  • Expensive per gigabyte of memory when compared to HDDs
  • Lower storage capacity than hard disks
  • Small size makes them easier to be lost, stolen or damaged
  • A card reader is needed if the computer has no card slot
Check your understanding
A laptop manufacturer replaces HDDs with SSDs. Give three benefits for the user.
  • The laptop is lighter and thinner, because an SSD has no platters or motor.
  • Longer battery life, because SSDs consume less power, and the machine runs cooler and quieter.
  • Faster - files and the operating system load more quickly, and the drive does not have to get up to speed.
  • More reliable when the laptop is carried around, because there are no moving parts to damage.
Give two reasons why a video-editing studio might still choose HDDs for its archive.
HDDs offer a larger maximum capacity and are cheaper per gigabyte, so storing many terabytes of footage costs far less. HDDs also have no write-endurance limit of the kind that affects flash memory.
Recap
  • Solid-state storage uses NAND flash with control and floating gates - no moving parts.
  • SSDs are faster, lighter, cooler and more reliable, but cost more per GB and have limited write endurance.
  • Pen drives and memory cards trade capacity for portability, and are easy to lose or steal.
  • SD, xD and CFast are the three memory card types named in the syllabus.
3.5

Internal Memory vs Backing Storage

The comparison examiners ask for

Internal memory (RAM and ROM)
  • Extremely fast data access but much smaller capacity
  • Much more expensive per byte
  • Directly addressable by the CPU
  • RAM is volatile - its contents are lost when the power is switched off
  • ROM is non-volatile and holds the start-up instructions
Backing storage (HDD, SSD, optical)
  • Holds its contents permanently (non-volatile), even when powered down
  • Much larger capacity and far cheaper per byte
  • Not directly addressable - data must be moved into RAM before the CPU can process it
  • Slower access than internal memory

Exam tip: if a question asks why a computer needs backing storage as well as RAM, the answer is volatility and capacity - RAM loses everything when the power goes off, and it is too small and too expensive to hold all a user's files.
Check your understanding
Why must a file be copied from the hard disk into RAM before it can be edited?
Backing storage is not directly addressable by the CPU, and it is far slower than RAM. The data must be loaded into RAM, which the CPU can access directly and quickly, before it can be processed.
State two differences between RAM and a solid-state drive, given that both are made from silicon chips.
RAM is volatile and loses its contents when the power is off, while an SSD is non-volatile. RAM is also much faster and much smaller in capacity, and is directly addressable by the CPU whereas the SSD is not.

  • I can state the difference between storage media and storage devices.
  • I can describe how magnetic, optical and solid-state storage each record data.
  • I can give characteristics, uses, advantages and disadvantages for tape, fixed and portable HDD, CD/DVD/Blu-ray, SSD, pen drive and memory cards.
  • I can compare CD, DVD and Blu-ray and explain why their capacities differ.
  • I can compare internal memory with backing storage on volatility, speed, capacity, cost and addressability.
