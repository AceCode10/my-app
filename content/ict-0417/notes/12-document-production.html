Cambridge IGCSE ICT 0417 · Practical skills

Document Production

These are the cross-application skills the practical papers test again and again: placing and editing images, laying out a document, using tables, headers and footers, applying consistent styles, proofing your work, and controlling page layout and text formatting.

Syllabus coverage: 12 Images · 13 Layout (13.1-13.3) · 14 Styles · 15 Proofing (15.1-15.2) · 17 Document production. The syllabus notes that in section 13 'document' means any of the applications used in sections 16 to 21 - so these skills apply to spreadsheets, presentations, databases and web pages too.
12

Images

Placing and editing an image

  • Place an image with precision - position it exactly where the question asks, aligned to a margin, a column or another object, not simply dropped near the right place.
  • Resize an image as specified, either maintaining the aspect ratio (dragging a corner handle, or locking the ratio in the size dialogue) or adjusting it deliberately when told to fit a given width and height.
  • Crop an image - cut away the parts you do not want, keeping the rest at full quality.
  • Rotate an image - turn it through a stated number of degrees.
  • Reflect (flip) an image horizontally or vertically - a mirror image, which is not the same as rotating it.
  • Adjust the brightness - make the whole image lighter or darker.
  • Adjust the contrast - increase or decrease the difference between the light and dark areas.
  • Group and layer images - group so several objects move and resize as one, ungroup to edit them separately, and move to the front or back to control which object is on top.
Aspect ratio is the ratio of width to height. Resizing without maintaining it leaves the image stretched or squashed, which loses marks unless the question asked for exact dimensions.

Reducing image file size

  • Reducing the image resolution - fewer pixels - reduces the file size.
  • Reducing the colour depth - fewer bits per pixel, so fewer colours - also reduces the file size.
  • Smaller images make documents open faster, keep web pages within a sensible download size, and let files be emailed within attachment limits.
  • Both methods lose quality permanently, so always keep the original file.
Check your understanding
What is the difference between rotating an image 180 degrees and reflecting it horizontally?
Rotating turns the image about its centre, so it appears upside down but the same way round. Reflecting produces a mirror image - left and right are swapped, so text would read backwards. They are only the same for a perfectly symmetrical image.
13.1

Create or Edit a Document

Entering and editing content

  • Enter and modify text and numbers with total accuracy - one wrong character can lose the mark for the whole item.
  • Use editing techniques to manipulate text and numbers: highlight, delete, move, cut, copy, paste, drag and drop.
  • Copy and paste rather than retyping, because retyping introduces errors.

Placing objects into the document

  • Text
  • Image
  • Screenshot
  • Shapes
  • Table
  • Graph or chart
  • Spreadsheet extract
  • Database extract
When a spreadsheet or database extract is placed in a document, check that all data and labels are fully visible - no truncated columns, no ####, and nothing split across a page break.

Text wrap

Text wrapping controls how the text flows around a table, chart or image. You must be able to apply:

Wrap settingWhat happens
AboveThe object sits on its own line with the text above it - nothing beside it
BelowThe object sits on its own line with the text continuing below it
SquareText flows around the rectangular bounding box of the object, leaving an even gap
TightText flows around the actual shape of the object, following its outline
13.2

Tables Within Documents

Creating and editing a table

  • Create a table with a specified number of rows and columns.
  • Place text or objects in a table, including images and charts inside cells.
  • Insert rows and columns, and delete rows and columns.
  • Merge cells - join two or more cells into one, typically for a heading spanning the table.

Formatting a table

  • Horizontal cell alignment - left, right, centre, fully justified.
  • Vertical cell alignment - top, middle, bottom.
  • Show gridlines or hide gridlines - read the question carefully, as both are asked for.
  • Wrap text within a cell so long entries are shown on several lines instead of being cut off.
  • Shading or colouring cells, for example to highlight a header row.
  • Adjust row height and adjust column width so that all contents are fully visible.
Exam habit: before printing, widen every column and deepen every row until nothing is hidden. Truncated data is one of the most common reasons for losing practical marks.
Check your understanding
A table heading must span all four columns. How is this done?
Select the four cells of the top row and merge cells to make them into a single cell, then enter the heading and centre it horizontally.
13.3

Headers and Footers

Creating and using headers and footers

  • Create or edit headers and footers in a range of software packages - word processor, spreadsheet, presentation and database report.
  • Align the contents consistently - to the left margin, the right margin or centred within the margins - and keep that alignment on every page.
  • Place text and automated objects in the header and footer:
    • File information - the file name and path
    • Page numbering
    • Total number of pages, for example "Page 2 of 7"
    • Date
    • Time
Automated means the field updates itself - the date shows today's date and the page number changes on every page, without being retyped.

The purpose of headers and footers

  • The same information appears on every page automatically, without retyping it.
  • Pages that become separated can be identified and put back in order.
  • They show whose work it is and which file and version it came from - which is how a practical examiner identifies your work.
  • They carry consistent corporate information such as a company name or logo, supporting the house style.
Check your understanding
Why is an automated page number better than typing the numbers by hand?
An automated field updates itself - if a page is inserted or deleted, every number renumbers correctly. Typed numbers would all have to be edited by hand, and would quickly become wrong.

Styles

Creating, editing and applying styles

A style is a named set of formatting instructions. Applying the style applies all of its formatting at once, and editing the style updates every piece of text that uses it.
  • Create a new style, modify and update an existing one, and apply styles to ensure consistency of presentation.

What a style can specify

Font
  • Font face - the name of the typeface
  • Type - serif (small strokes on the letters, easier to read in long printed passages) or sans-serif (no strokes, cleaner on screen)
  • Point size
  • Colour
Paragraph
  • Text alignment - left, right, centre, fully justified
  • Text enhancement - bold, underline, italic
  • Spacing - paragraph spacing before and after, and line spacing
  • Bullets - shape, alignment, line spacing and indent
Why use styles rather than direct formatting? Every heading is guaranteed identical; changing one style restyles the whole document in a second; and the document keeps to the house style without anyone having to remember the settings.

Corporate house style

A corporate house style is the set of rules an organisation uses for the appearance of all its documents - fonts, sizes, colours, logo placement, headings and layout.

Purpose and uses

  • Makes every document instantly recognisable as belonging to the organisation, strengthening its brand.
  • Gives a professional and consistent appearance, which builds trust.
  • Saves staff time - the decisions are already made and stored as styles or templates.
  • Makes documents easier to read, because readers know where to look for each kind of information.
  • Ensures required information, such as a company registration number, always appears.
Check your understanding
A 60-page report must have all sub-headings changed from 14 pt to 16 pt. Explain how styles make this a one-step job.
If every sub-heading was formatted using the same style, editing that style to 16 pt updates every sub-heading in the document at once. Without styles, each of the sub-headings would have to be found and reformatted individually, which is slow and easy to get wrong.
Give one reason a company insists on a house style.
Every document looks consistent and instantly recognisable as the company's own, which presents a professional image and strengthens the brand. It also saves staff time and makes documents easier to read.
15.1

Proofing: Software Tools

Reducing errors with automated tools

  • Use spell check and grammar check, and make appropriate changes so the work contains as few errors as possible.
  • Use validation routines to minimise data entry errors.

The limits of spell check software

  • Automated suggestions do not always give the correct response - the software cannot know what you meant.
  • A correctly spelled but wrong word is not detected: form for from, their for there, bee for be.
  • Names, places and technical terms are flagged as errors even though they are correct.
  • The dictionary may use a different variety of English, so correct spellings are marked wrong.
  • This is why the work must still be proofread by a person.

Validation checks

Validation is an automatic check by the computer that entered data is reasonable and of the right type. It cannot prove the data is correct.
CheckWhat it testsExample
Range checkThe value lies between stated limitsA percentage must be 0 to 100
Character checkOnly permitted characters are usedA surname must contain no digits
Length checkThe entry has the right number of charactersA product code must be exactly 6 characters
Type checkThe entry is of the correct data typeQuantity must be numeric
Format checkThe entry follows a stated patternA date entered as dd/mm/yyyy
Presence checkThe field is not left emptyAn email address must be entered
Importance: validation traps impossible data at the moment it is entered, before it reaches the file - which is far cheaper than finding and correcting it later.
15.2

Proofing Techniques

Visual verification and proofreading

Verification is checking that data has been copied or entered correctly - that it matches the original source.

Two methods of verification

  • Visual checking - the entered data is compared, on screen or on a printout, against the original document by a person.
  • Double data entry - the data is entered twice, often by two different people, and the computer compares the two versions and reports any difference.

Data entry errors to identify and correct

  • Transposed numbers - 1243 typed for 1234
  • Incorrect spelling
  • Inconsistent character spacing - two spaces after one full stop and one after another, or a space before a comma
  • Inconsistent case - some headings in capitals and others in sentence case

Proofreading for layout

  • Identify and correct inconsistent line spacing.
  • Remove blank pages or slides left at the end of the file.
  • Remove widows and orphans - a widow is the last line of a paragraph left alone at the top of a page; an orphan is the first line of a paragraph left alone at the bottom.
  • Correct inconsistent or incorrect application of styles.
  • Ensure that tables and lists are not split over columns, pages or slides.
The need for both: validation checks the data is sensible; verification checks it is the same as the original. A pupil aged 14 typed as 15 passes every validation check, so only verification will catch it - and data that is verified but never validated may be faithfully copied nonsense.
Check your understanding
Explain the difference between validation and verification with an example.
Validation is an automatic computer check that data is reasonable - a range check would reject an age of 150. Verification is a check that the data matches the original source - if a pupil aged 14 is typed as 15, validation accepts it because 15 is reasonable, and only visual checking or double data entry against the original form will find the error.
Define a widow and an orphan.
A widow is the last line of a paragraph pushed onto the top of the next page on its own. An orphan is the first line of a paragraph left on its own at the bottom of a page. Both look untidy and should be removed.
17

Document Production

Organising page layout

  • Page size - for example A4 or A5
  • Page orientation - portrait or landscape
  • Page margins - top, bottom, left and right
  • Number of columns, the column width and the spacing between columns
  • Set and remove breaks - page breaks, section breaks and column breaks

The purpose of breaks

  • A page break forces the following text to start at the top of a new page, so a heading is not stranded at the foot of a page and a table is not split.
  • A section break divides the document so that different parts can have different layouts - for example one landscape page for a wide table, or a different number of columns, or different headers and footers.
  • A column break forces the following text to the top of the next column, so a sub-heading starts a new column.
  • Using breaks rather than pressing Enter many times keeps the layout correct when the text is later edited.

Gutter margin

A gutter margin is extra space added to the inside edge of each page, on top of the normal margin.
  • Its purpose is to leave room for binding, stapling or hole-punching.
  • Without it, text near the spine would be hidden or cut off when the document is bound.
  • On double-sided documents the gutter alternates between the left and right edges so it is always on the inside.

Formatting text

  • Line spacing - single, 1.5 times, double, multiple, and spacing before and after paragraphs.
  • Tabulation - left, right, centred and decimal tabs, which align numbers on the decimal point.
  • Indented paragraphs - the whole paragraph, or its first line, is moved in from the margin.
  • Hanging paragraphs - the first line starts at the margin and all following lines are indented, which is how bibliographies and glossaries are set out.
  • Text enhancement - bold, underline, italic, superscript and subscript, and changes in case.
  • Lists - create or edit bulleted and numbered lists, controlling the bullet shape, alignment, line spacing and indent.
Consistency is marked. Use the same line spacing, the same spacing between paragraphs and the same list style throughout, unless the question asks otherwise.

Find and replace, and navigation

  • Find and replace text throughout a document, using the options:
    • Match case - so that ICT is not confused with ict
    • Whole words only - so that replacing art does not change start and party
  • Add and delete bookmarks and hyperlinks to navigate a long document - a bookmark marks a place, and a hyperlink jumps to it, to another file, to a website or to an email address.
Check your understanding
A report is to be bound along the left edge. Which setting should be used and why?
A gutter margin on the left. It adds extra space on the binding edge so that the text is not hidden or cut off when the pages are bound or hole-punched.
Why is a section break, not a page break, used to make one page landscape in a portrait report?
Orientation is a section-level setting. A section break divides the document so that the new section can have a different layout - landscape - while the rest of the document stays portrait. A page break only moves text to a new page and cannot change orientation.
Why should "Whole words only" be used when replacing the word "cat"?
Without it, the replacement would also change cat inside other words such as catalogue, category and allocate, corrupting the document.
Document production checklist
  • I can place, resize, crop, rotate, reflect, brighten, contrast, group and layer images, and reduce their file size.
  • I can enter and edit text accurately and place text, images, screenshots, shapes, tables, charts and spreadsheet or database extracts.
  • I can apply above, below, square and tight text wrap.
  • I can create, edit and format tables, including merging cells, alignment, gridlines, shading and sizing.
  • I can create headers and footers with aligned text and automated file information, page numbers, total pages, date and time, and state their purpose.
  • I can create, modify, update and apply styles covering font, alignment, enhancement, spacing and bullets, and explain corporate house style.
  • I can use spell check and grammar check and explain their limits, and name the six validation checks.
  • I can verify by visual checking and double data entry, and proofread for widows, orphans, split tables and inconsistent styles.
  • I can set page size, orientation, margins, columns and breaks, and explain pagination and gutter margins.
  • I can set line spacing, tabulation, indented and hanging paragraphs, text enhancement and lists, and use find and replace with match case and whole words.
