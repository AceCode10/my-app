Spreadsheets

The spreadsheet task carries the heaviest weighting of any single practical skill. The marks are in the formulae - whether they use the right functions, the right cell references, and whether they replicate correctly down a column.

Syllabus coverage: 20.1 Create a data model · 20.2 Manipulate data · 20.3 Present data · 16 Graphs and charts
20.1

Create a Data Model

Creating and editing a spreadsheet model

  • Insert cells, rows and columns, and delete cells, rows and columns.
  • Merge cells, typically for a title spanning several columns.
  • Check after inserting or deleting that no formula now refers to the wrong cell.

Formulae and functions

A formula is a calculation you write yourself using cell references and operators, for example =B4*C4. A function is a ready-made operation built into the software that is given arguments, for example =SUM(B4:B20). Both are entered beginning with =.

Arithmetic operators

  • + add · - subtract · * multiply · / divide · ^ indices (raise to a power)

Order of operations

  • Operations are carried out in this order: Brackets, Indices, Division and Multiplication, Addition and Subtraction.
  • Division and multiplication rank equally and are worked left to right; so do addition and subtraction.
  • Use brackets to make sure formulae work. =A1+A2/2 halves A2 only; =(A1+A2)/2 gives the average of the two - which is almost always what was wanted.

Cell referencing

Relative reference - B4
  • Changes when the formula is replicated. Copied one row down, B4 becomes B5
  • Use it when each row must use its own data
Absolute reference - $B$4
  • Stays fixed when the formula is replicated, because the $ signs lock the column and the row
  • Use it when every row must refer to the same cell - a tax rate, an exchange rate, a fixed price
  • A mixed reference locks only one part: $B4 fixes the column, B$4 fixes the row

Named cells and named ranges

  • A cell or range can be given a name, and that name used in formulae: =B4*VAT_Rate.
  • A name behaves like an absolute reference, so it does not change when replicated.
  • Names make formulae far easier to read and check, and reduce mistakes.
Replication is where marks are won and lost. Before copying a formula down a column, ask of every reference: "should this move with the row, or stay still?" If it should stay still, it needs $ signs or a name.

Functions you must be able to use

Nested functions

  • A nested function is a function used inside another function.
  • =IF(B4>=70,"Distinction",IF(B4>=40,"Pass","Fail")) - an IF inside an IF, to choose between three outcomes.
  • =ROUND(AVERAGE(B4:B20),2) - the average is calculated first, then rounded.
  • Work from the inside out when checking a nested formula, and count the brackets.

External data sources

  • A formula can refer to a cell in another worksheet - =Prices!B4 - or in another file.
  • This keeps one master copy of shared data, so it only has to be updated in one place.
  • The linked file must remain available, or the formula will fail.
Check your understanding
A VAT rate is in cell H1. Write the formula in C4 to add VAT to the price in B4, so that it can be replicated down to C20.
=B4*(1+$H$1). B4 is relative so it becomes B5, B6 and so on as the formula is copied down, but $H$1 is absolute so every row still refers to the single VAT rate cell. Naming H1 as VAT and writing =B4*(1+VAT) would work equally well.
Explain the difference between VLOOKUP and HLOOKUP.
VLOOKUP searches for the value down the first column of the lookup table and returns an item from a numbered column to the right. HLOOKUP searches along the first row and returns an item from a numbered row below. Use VLOOKUP when the table is arranged in columns and HLOOKUP when it is arranged in rows.
What is the difference between a formula and a function?
A formula is a calculation the user writes from cell references and operators, such as =B4*C4. A function is a ready-made operation built into the software that is given arguments, such as =SUM(B4:B20). A formula may contain functions.
20.2

Manipulate Data

Sorting

  • Sort into ascending or descending order using a single criterion or multiple criteria.
  • Always select all the columns of the data before sorting. Sorting one column alone scrambles the rows and destroys the data.
  • Tell the software whether the data has a header row, so the headings are not sorted with the data.

Searching and selecting

  • Select subsets of data using a single criterion or multiple criteria, normally with a filter.
  • Operators: AND, OR, NOT, >, <, =, >=, <=, <>.
  • Perform searches using wildcards - * for any number of characters and ? for exactly one.
  • Remember that AND narrows the results and OR widens them.
Check your understanding
Why must the whole table be selected before sorting?
If only one column is selected, only that column is reordered while the other columns stay where they are. Each row's data then belongs to the wrong record, and the data is corrupted beyond repair.
20.3

Present Data

Adjusting the display features

  • Display either formulae or values - the formula view is normally required as evidence, and the value view to show the results.
  • Adjust row height, column width and cell sizes so that all data, labels and formulae are fully visible.
  • Wrap text within cells so long labels appear on several lines instead of being cut off.
  • Hide and display rows and columns, for example to print only the columns that are needed.
The single most common practical error: printing the formula view with the columns too narrow, so the formulae are truncated. Widen every column first, and check no cell shows ####.

Formatting a spreadsheet

  • Enhance the spreadsheet with text colour, cell colour, bold, underline, italic and shading.
  • Format numeric data appropriately:
    • a stated number of decimal places
    • different currency symbols
    • percentages
  • Use conditional formatting to change the display format depending on the contents of a cell - for example showing every value below 40 with a red background, so exceptions stand out automatically and update themselves when the data changes.

Setting the page layout for printing

  • Set the orientation to portrait or landscape - landscape usually suits a wide table or the formula view.
  • Control the page layout to print:
    • a specified number of pages, by scaling the sheet to fit
    • a defined print area, so only the required range is printed
    • display or hide gridlines
    • display or hide row and column headings - the numbers and letters, which are usually needed as evidence in the formula view
  • Add headers and footers with your name, the file name and the page number.
Check your understanding
Why are row and column headings usually displayed when printing the formula view?
They show which cell each formula is in, so the examiner can check that the references are correct. Without the row numbers and column letters the formulae cannot be matched to their cells.
Give one use of conditional formatting.
Highlighting values that meet a condition automatically - for example shading every mark below 40 in red so failing grades stand out at a glance. The formatting updates itself whenever the data changes.
16

Graphs and Charts

Selecting data and choosing the chart type

  • Select the data to produce a graph or chart using:
    • Contiguous data - ranges next to each other, selected in one drag
    • Non-contiguous data - separate ranges, selected by holding the Ctrl key while dragging each one
    • Specified data ranges - exactly the rows and columns the question names
  • Always include the labels as well as the values, so the chart is labelled automatically.
Chart typeBest for
Pie chartShowing the proportion each item contributes to a whole - one data series only
Bar or column chartComparing separate categories against each other
Line graphShowing a trend over time or a continuous change
Scatter graphShowing the relationship between two variables
Comparative / stacked chartsComparing two or more data series on the same axes

Labelling a graph or chart

All of these must be set correctly when the question asks for them:

  • Chart title
  • Legend - naming each data series (a pie chart with sector labels usually needs no legend)
  • Sector labels, sector values and percentages on a pie chart
  • Category axis title and value axis title
  • Category axis labels and value axis labels
  • Data value labels on the bars, points or sectors

Editing and enhancing a chart

  • Add a second data series, so two sets of values are compared on the same chart.
  • Add a second axis, needed when the two series use very different scales - for example rainfall in millimetres and temperature in degrees.
  • Format numerical values to a specified number of decimal places.
  • Format numerical values to display currency symbols.
  • Adjust the maximum and minimum values of an axis scale and set the incremental values (the interval between gridlines), so the data fills the chart and is easy to read.
  • Enhance the appearance by extracting (exploding) a pie chart sector to draw attention to it, and by changing the colour scheme or fill patterns.
Choosing well is a marked skill. A pie chart cannot show a trend, and a line graph cannot show proportions of a whole. Read what the chart is meant to communicate before choosing its type.
Check your understanding
Monthly sales for two products over a year are to be compared. Which chart type suits this, and why?
A line graph with two data series, because the data is over time and a line graph shows the trend for each product and lets the two be compared directly. A pie chart could not be used, as it only shows proportions of a single total.
Rainfall (0-300 mm) and temperature (0-35 degrees) are plotted on one chart. What must be added and why?
A second axis. The two series use very different scales, so plotted against one axis the temperature line would be almost flat along the bottom. A second value axis lets each series use its own scale and stay readable.
How do you select the names in column A and the totals in column E, ignoring columns B to D?
Select column A, then hold the Ctrl key and select column E. This is a non-contiguous selection, so only the two required ranges are charted.
Spreadsheets and charts checklist
  • I can insert, delete and merge cells, rows and columns.
  • I can write formulae with +, -, *, / and indices, and apply the correct order of operations using brackets.
  • I can explain the difference between a formula and a function.
  • I can use relative and absolute references and named cells and ranges, and replicate formulae correctly.
  • I can use SUM, AVERAGE, MAX, MIN, INT, ROUND, COUNT, LOOKUP, VLOOKUP, HLOOKUP, XLOOKUP and IF, including nested functions and external data.
  • I can sort on single and multiple criteria and filter with AND, OR, NOT, comparison operators and wildcards.
  • I can switch between formula and value view and make sure everything is fully visible.
  • I can format cells, numbers, currency and percentages, and apply conditional formatting.
  • I can set orientation, print area, page count, gridlines and row and column headings for printing.
  • I can select contiguous and non-contiguous data, choose the right chart type, label it fully, add a second series and a second axis, set axis scales, and enhance it.
