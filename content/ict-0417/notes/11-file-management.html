Cambridge IGCSE ICT 0417 · Practical skills

File Management

File management is tested in every practical paper, not as a question of its own but through the file names, formats and folders you are told to use. Marks are lost every session for saving in the wrong format or under the wrong name, so this is some of the cheapest marks on the course.

Syllabus coverage: 11.1 Manage files effectively · 11.2 Reduce file sizes for storage or transmission
11.1

Manage Files Effectively

What you must be able to do

  • Locate stored files - navigate a folder structure and use the search facility to find a file by name, type or date.
  • Open and import files of different types - including opening a .csv or .txt file into a spreadsheet or database, and importing text into a presentation.
  • Save files in a planned hierarchical directory/folder structure - a logical tree of folders and sub-folders, so files can be found again.
  • Save files using appropriate file names - short, meaningful names that describe the content and version.
  • Save and print files in a variety of formats.
  • Save and export in the file format of an application package.
  • Save and export in a generic file format.

Planning a hierarchical folder structure

  • A hierarchical structure is a tree: a top-level folder containing sub-folders, which may themselves contain sub-folders.
  • Group files by subject, task or date - whichever you will search by later.
  • Keep the structure shallow enough to navigate, but deep enough that no folder holds hundreds of unrelated files.
  • Use the same naming pattern throughout, so folders sort sensibly.
Why it matters
  • Files are found quickly, which saves time
  • Related files are kept together, so nothing is missed when work is backed up or submitted
  • Reduces the risk of overwriting the wrong file or losing work

Choosing a good file name

Do
  • Describe the content: sales_report_2026.xlsx
  • Include a version or date where it helps: menu_v2.docx
  • Use the name the question asks for, exactly, including capitals
  • Keep the correct file extension
Do not
  • Use names such as doc1, new or final final
  • Use characters the operating system forbids, such as \ / : * ? " < > |
  • Change or remove the extension
  • Save every task over the same file
Exam tip: in the practical papers the file name is part of the mark scheme. If the question says save as N11REPORT, save it as exactly that - not N11 report.

Saving and printing in a variety of formats

You must be able to produce, save and print:

  • A document
  • Screenshots - evidence of settings, formulae or a query design
  • Database reports
  • Data tables, including a spreadsheet displaying formulae rather than values
  • Graphs and charts
  • A web page in browser view - how it appears to a visitor
  • A web page in HTML view - the source code itself
When printing evidence, always check that all data and labels are fully visible - nothing truncated, no column showing ####, no row split across two pages. A printout that hides the answer scores nothing.

File formats

Application (proprietary) formats

  • .docx / .doc - word processed documents
  • .xlsx / .xls - spreadsheets
  • .sdb, .sdc, .accdb, .odb - database and spreadsheet files of particular packages
  • .rtf - rich text format, which keeps basic formatting and opens in almost any word processor
  • .pptx / .ppt - presentations

The need for generic file formats

  • A proprietary format can often only be opened by the package that created it, or by the same version of it.
  • A generic format can be opened on any computer, by many different packages and on any operating system.
  • This makes data exchange between organisations possible, and keeps files readable in the future when the original software is gone.
  • Generic files are usually smaller, because they hold less package-specific information.
  • The trade-off is that some formatting and features are lost - a .csv keeps the data but not the colours, formulae or column widths.
Check your understanding
Why would you export a price list as .csv rather than .xlsx to send to a supplier?
.csv is a generic format that can be opened by any spreadsheet or database package on any system, so the supplier does not need the same software. It is also a much smaller file. The drawback is that formatting, formulae and multiple sheets are lost - only the data survives.
State one difference between .jpg and .png, and say when each should be used.
.jpg uses lossy compression, so some quality is permanently lost but the file is small - best for photographs. .png uses lossless compression and supports transparency, so no quality is lost - best for screenshots, diagrams and logos.
Why is a report sent to a customer as .pdf rather than .docx?
A .pdf keeps the layout, fonts and images exactly as designed on any computer, and it cannot easily be edited, so the customer cannot change the content by accident. A .docx may reflow or lose fonts if the customer's software differs.
11.2

Reduce File Sizes for Storage or Transmission

The need to reduce file sizes

  • Storage - smaller files use less disk space, so more can be stored and backups are quicker and cheaper.
  • Transmission - smaller files upload, download and email faster, and use less bandwidth and less mobile data.
  • Email systems impose an attachment size limit; an oversized file will simply be rejected.
  • Web pages with smaller images load faster, which keeps visitors and suits users on slow connections.
  • Several files can be combined into a single archive, so nothing is lost or forgotten when sending.

How file sizes are reduced

File compression (.zip, .rar)
  • Compression software encodes the data so it takes fewer bytes, and the file is restored by extracting it
  • Many files and folders can be combined into one archive
  • Lossless - the original file is restored exactly, which is essential for documents, spreadsheets and programs
  • The recipient needs software that can open that archive type
Reducing an image file
  • Reduce the image resolution - fewer pixels means a smaller file
  • Reduce the colour depth - fewer bits per pixel means fewer colours and a smaller file
  • Crop the image so only the part that is needed is stored
  • Save in a compressed format such as .jpg
  • This is lossy: quality is permanently lost, so keep the original
Lossy or lossless? Lossy compression discards data the viewer is unlikely to notice and cannot be undone - it suits photographs, music and video. Lossless compression loses nothing and must be used for text, data files and programs, where a single changed byte would corrupt the file.
Check your understanding
A 40 MB folder of documents must be emailed, but the limit is 10 MB. Explain what to do.
Compress the folder into a .zip archive. Compression is lossless, so the documents are restored exactly when the recipient extracts them, and putting everything into a single archive means no file is forgotten. If it is still too large, the files should be shared through cloud storage and a link sent instead.
State two ways of reducing the file size of a photograph for a web page.
Reduce the image resolution, so there are fewer pixels to store, and reduce the colour depth, so fewer bits are used for each pixel. Cropping to the part actually needed and saving as .jpg also reduce the size.
File management checklist
  • I can locate, open and import files of different types.
  • I can plan and use a hierarchical folder structure and choose appropriate file names.
  • I can save and print documents, screenshots, database reports, data tables, charts, and a web page in both browser and HTML view.
  • I can save and export in application formats (.docx, .xlsx, .accdb, .rtf, .pptx) and generic formats (.csv, .txt, .rtf, .pdf, .css, .htm, .jpg, .png).
  • I can state the characteristics and uses of css, csv, gif, htm, jpg, pdf, png, rtf, txt, zip and rar.
  • I can explain the need for generic file formats.
  • I can explain why file sizes are reduced, and reduce them by compression or by lowering resolution or colour depth.
